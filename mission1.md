2.  **3 most interesting folders in the Linux kernel:**
    - `drivers/`: This directory contains all hardware device drivers, which are essential for the kernel to communicate with various hardware components like keyboards, GPUs, and network cards.
    - `fs/`: It implements different file systems (such as ext4 and Btrfs), responsible for how data is stored and organized on disks.
        - `net/`: This folder houses the entire network stack, including the TCP/IP protocols, enabling all internet and network communication functions.
